# dup-finder

Finds duplicate files in a directory and its subdirectories.

## Install

```bash
curl -L https://raw.githubusercontent.com/neuralmint/dup-finder/main/dup-finder.py -o /usr/local/bin/dup-finder
chmod +x /usr/local/bin/dup-finder
```

Run `dup-finder --help` for usage.
